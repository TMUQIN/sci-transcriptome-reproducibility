# Figure Assembly Status

The public repository is synchronized to the manuscript-facing figure
organization:

- Main figures: Fig. 1 analytical sample reconstruction; Fig. 2 gene/Hallmark
  transfer; Fig. 3 effect-strength sensitivity; Fig. 4 method-specific
  Hallmark support; Fig. 5 focal-program context-dependent transfer profiles.
- Supplementary figures: Fig. S1 composition sensitivity; Fig. S2 estimability;
  Fig. S3 equal-feature-count diagnostic; Fig. S4 GSE47681 QC; Fig. S5
  conditional member stability; Fig. S6 matched-set exchangeability.

The final presentation assembly used historical plotting infrastructure that
depends on project-level `reports/`, `results/` and helper modules not included
in this minimal public release. Therefore this repository does **not** claim
clean-clone, pixel-identical regeneration of the published TIFF figures.

The archived `data/`, `tables/`, `provenance/` and analysis scripts support
inspection and reconstruction of the numerical source tables. The former
v5.3.3 figure builder is retained under `scripts/legacy/` for provenance only;
it is not the current figure map or a supported release command.
