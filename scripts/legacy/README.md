# Legacy figure builder

`72_build_v5_3_3_figures.py` is retained from the earlier repository
preparation branch for provenance. It describes an obsolete figure hierarchy
and must not be used to regenerate the current manuscript figures.

The current manuscript-facing figure organization is documented in
`docs/figure_reproduction_map.md`. Final presentation assembly depended on
project-level plotting infrastructure that is not part of this minimal public
repository.
