# Effect-strength sensitivity protocol

This subsequent sensitivity analysis uses mean absolute study score (moderated t for genes; NES for Hallmarks), common pooled quartiles across the three contrasts, and the common 10th-90th percentile window of the cross-sectional day-7-versus-day-1 contrast. It is descriptive, does not select features or change the predefined discovery matrices, and does not establish that signal strength is irrelevant.
